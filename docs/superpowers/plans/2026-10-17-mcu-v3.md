# BonettoR32V MCU (contract v3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a working, gate-verified RV32E microcontroller that fits and hardens clean in one TT
sky130 1x1 tile. It runs code from the TT QSPI Pmod's flash, keeps data in its PSRAM, and carries
the contract-v3 peripherals. This is the base for the CoreMark performance loop.

**Architecture:** two parallel streams on separate branches, joined by one integration swap.
- **Gates** (`setup/v3-gates`):
  - pin-level C++ models of the two Pmod chips;
  - a v3 ISS with CSRs, traps and interrupts;
  - peripheral pin checkers, v3 programs, and an updated cosim runner, eval and gate-level test.
- **Seed** (`setup/v3-seed`): the H005 core, given the v3 memory controller, CSRs and traps, plus
  a simple, correct peripheral block.

`main` keeps the v2 gates and contract until Task 9 swaps everything at once. Formal v3 (Task 10)
follows the swap. It is needed only at the tenth merged improvement and at final signoff.

**Tech Stack:** C++17 + Verilator (cosim), Python 3 stdlib (runners, tools), riscv32-unknown-elf
GCC (`-march=rv32e_zicsr -mabi=ilp32e`), cocotb + Icarus (gate-level test), yosys/LibreLane 3.0.14
(area, harden), SBY + riscv-formal on hwe-bench (Task 10).

**Spec:**
- `docs/contract-v3.md`: binding; section numbers below refer to it.
- `docs/superpowers/specs/2026-10-17-mcu-v3-draft.md`: rationale.

## Global Constraints

- Every rule in `CLAUDE.md` applies: Opus agents, one task per agent in its own worktree, commits
  with `git -c commit.gpgsign=false commit`, no force pushes, and the lead merges.
- Branches: gates tasks 1-7 on `setup/v3-gates`, seed task 8 on `setup/v3-seed`. Neither touches
  `docs/contract.md`, `CLAUDE.md` or `src/config.json`; Task 9 does.
- Contract v3 values are used verbatim from `docs/contract-v3.md`:
  - chip command tables (2.2, 2.3);
  - power-up modes (2.4);
  - the memory map (3);
  - CSR numbers and behaviors (4);
  - peripheral slots and bit positions (5.1);
  - the 2,048-cycle latency cap (4);
  - tCEM = 320 cycles at T = 25 ns (2.1.7);
  - the core region at PSRAM `0x7F_FF80-0x7F_FFFF` / CPU `0x017F_FF80` (3).
- The cosim harness stays one Verilator main built in two modes (rvfi and pins), as in v2. Its
  last stdout line stays a JSON summary; exit 0 = pass, 1 = fail, 2 = setup error.
- Tools stay Python 3 stdlib only. C++ stays C++17 with no new dependencies.
- Every program ends with `jal x0, 0` retired twice at the same pc (contract 4, program end).
- Clock for all cycle conversions: T = 25 ns (40 MHz). Pass it as `--clk-ns 25` where a tool
  needs it.

## Review Focus

1. **The memories start in a non-default mode** (flash in continuous read, PSRAM in QPI or not
   yet reset). A core that only boots from clean chips must fail. Pinned by Task 1's
   `test_reset_sequence_from_every_state` and Task 5's seed → mode mapping.
2. **An interrupt lands mid-instruction, during WFI, or right after an MRET that re-enables
   interrupts.** `mepc` must point at the next unexecuted instruction, including after a taken
   branch. Pinned by Task 4's `irq_stress` program.
3. **A store followed at once by a load or fetch of the same PSRAM address**, including code
   written to PSRAM and then executed. Write buffers must not return stale data. Pinned by
   Task 4's `coherence` program.
4. **UART RX at ±1% of the nominal bit time, and a second byte arriving while RX_FULL = 1**
   (overrun drops it). Pinned by Task 3's `test_uart_rx_rate_and_overrun` and Task 4's
   `uart_echo`.
5. **A PSRAM transaction that pauses SCK with CS_n low past 320 cycles** (a bit-serial core that
   stalls mid-transaction). It must fail loudly. Pinned by Task 1's `test_tcem_limit` and Task 5's
   `tcem_stall` mutant.

### Task 1: QSPI Pmod chip models

**Files:**
- Create:
  - `verif/cosim/pmod.h`: `QspiFlash`, `Psram`, `PmodBus`;
  - `verif/cosim/pmod_capi.cpp`: a C API for ctypes;
  - `verif/cosim/test_pmod.cpp`: a unit-test main;
  - `verif/cosim/test_pmod.py`: pytest that builds and runs it.
- Modify: `verif/cosim/build.sh` (also build `build/cosim/libpmod.so` and `build/cosim/test_pmod`).

**Interfaces:**
- Produces, in `pmod.h`:
  - `enum class FlashMode { Standard, Continuous }`.
  - `enum class PsramMode { SpiUninit, Spi, Qpi }`.
  - `struct PmodInit { FlashMode flash; PsramMode psram; }` and
    `PmodInit pmod_init_for_seed(uint32_t seed)`, which maps `(seed - 1) % 4` to
    {Standard+SpiUninit, Continuous+SpiUninit, Standard+Qpi, Continuous+Qpi}.
  - `struct PsramWrite { uint64_t t; uint32_t addr; uint8_t data; }` (addr = 23-bit byte
    address).
  - `class PmodBus`:
    - `PmodBus(uint32_t noise_seed, const uint8_t* flash_image /* 16 MiB */, PmodInit init, double clk_ns)`;
    - `bool edge(uint64_t t, uint8_t uio_out, uint8_t uio_oe)`: call once per rising clk edge
      with the design's outputs after that edge. Returns false and sets `error()` on the first
      violation of contract 2.1-2.4;
    - `uint8_t uio_in() const`: the input byte for the next cycle (memory outputs on SD lines
      while driven, noise elsewhere);
    - `const std::string& error() const`;
    - `const std::vector<PsramWrite>& writes() const`;
    - `uint8_t psram_byte(uint32_t a) const`, with 8 MiB of PSRAM state;
    - `bool psram_initialized() const`;
    - `uint64_t flash_reads() const`, `uint64_t psram_reads() const` (bytes, for stats).
- Produces, in `pmod_capi.cpp` (`extern "C"`): `void* pmod_new(uint32_t seed, const uint8_t* img, int flash_mode, int psram_mode, double clk_ns)`, `int pmod_edge(void*, uint64_t t, uint8_t out, uint8_t oe)`, `uint8_t pmod_uio_in(void*)`, `const char* pmod_error(void*)`, `void pmod_free(void*)`.

  - `test_flash_program_ignored`: 0x02 with data leaves the image unchanged and is not an error; 0x06 is an error ("illegal command").
  - `test_psram_requires_reset`: with `SpiUninit`, a 0x03 read before `0x66`/`0x99` fails with "PSRAM access before reset".
  - `test_psram_spi_rw`: after the reset, 0x02 at 0x7FFFFE writes 4 bytes wrapping to 0x000000 and 0x000001; 0x03 reads them back.
  - `test_psram_quad_and_qpi`: 0x38 and 0xEB in SPI mode; after 0x35, 0x0B (4 waits), 0xEB (6 waits) and 0x02 in QPI; 0xF5 returns to SPI mode.
  - `test_reset_sequence_from_every_state`: for each of the 4 `pmod_init_for_seed` states, contract 2.4's sequence followed by a flash 0x03 and a PSRAM 0x02 + 0x03 passes with correct data.

  - `test_waveform_rules`: CS_n changing with SCK high fails; both CS_n low fails; SCK high with both CS_n high fails; core data changing across a rising SCK edge fails; uio_oe[0], [3], [6] or [7] = 0, or uio_out[7] = 0, fails.

- [ ] **Step 3: Implement `pmod.h`** per contract 2.1-2.4.
  - Each chip is a state machine fed by rising SCK edges while its CS_n is low.
  - Fields:
    - command phase, then address phase (24 bits, single or quad);
    - mode, or dummy/wait;
    - data phase (single or quad, read or write).
  - Ending a transaction clears the per-transaction state. Mode changes (continuous read, QPI,

  - Memory outputs follow contract 2.1.5: valid from the rising edge until SCK falls, with noise

    `tcem = floor(8000 / clk_ns)`, and the per-command maximum SCK rate (shortest high + low phase
    in cycles × clk_ns ≥ 1000 / max_MHz).

### Task 2: ISS v3

**Files:**
- Create: `verif/cosim/iss3.h`, a new file (v2's `iss.h` stays until Task 9 deletes it).
- Modify: `verif/cosim/iss_main.cpp` (v3 options), `verif/cosim/test_iss.py` (v3 cases).

**Interfaces:**
- Produces, in `iss3.h`:
  - `class Iss3`:
    - `Iss3(const uint8_t* flash_image)`, holding 16 MiB of flash and sparse 8 MiB of PSRAM
      initialized to a seed pattern;
    - `void reset()`: pc = 0, MIE = MEIE = 0, x1..x15 = 0 by convention (the RTL's are
      arbitrary; programs clear them);
    - `Retire step(const IoHooks& io)`: one instruction;
    - `Retire take_interrupt()`: interrupt entry with no instruction (contract 4);
    - `bool irq_allowed() const`, which is MIE && MEIE;
    - `uint8_t psram(uint32_t a) const`;
    - `bool touched_region` (sticky).
  - `struct IoHooks { std::function<uint32_t(uint32_t slot, uint32_t iss_value)> volatile_read; }`.
    It supplies the DUT's value for volatile bits. In rvfi mode that is `rvfi_mem_rdata`; in pins
    mode it may be null for programs without volatile reads.
  - `struct Retire`: v2's fields plus `bool intr, trap; uint32_t mcause_after;`.
  - `struct IoRegs`: the ISS model of slot values (contract 5.1). The volatile masks per slot
    are: GPIO_IN all; TIMER_CNT all; TIMER_CAP all; UART_DATA read; UART_CTRL[15:13];
    SPI_DATA read; SPI_CTRL[4]; IRQ_PEND all; GPIO_EPEND all.
- `iss_main` CLI: `iss_main <prog.hex> [--max N] [--json]`. It prints the retired count, the
  uo_out GPIO-mode trace and the end reason ("selfloop" | "max" | "region").

- [ ] **Step 1: Write the failing tests** (pytest drives `iss_main` on tiny assembled programs
  built by the test with the cross GCC, as v2's `test_iss.py` does):
  - `test_csr_rw`: CSRRW/S/C and the immediate forms on every contract-4 CSR return the old value; read-only and hardwired fields hold (`mstatus` MPP reads 3, `mtvec[1:0]` reads 0, `mepc[1:0]` reads 0, `misa` reads 0).
  - `test_sync_traps`: ECALL → mcause 11, EBREAK → 3, misaligned JAL target → 0, `0x00000000` → 2. Each has mepc = pc, MPIE = old MIE, MIE = 0, and the next pc = mtvec. MRET returns, MIE = MPIE, MPIE = 1.
  - `test_interrupt_entry`: with MIE = MEIE = 1, `take_interrupt()` sets mepc = the next pc, mcause = 0x8000000B, pc = mtvec, and `Retire.intr`.
  - `test_memory_map`: flash at 0x0, PSRAM at 0x0100_0000 aliasing every 8 MiB, a store to flash changes nothing, IO at 0x8000_0000 aliasing on addr[6:2], misaligned PSRAM loads and stores bytewise.
  - `test_io_byte_lanes`: an SB to byte 1 of TIMER_CTRL changes bits [15:8] only; IRQ_PEND W1C on bits 0-1; reading UART_DATA byte 0 clears RX_FULL in the model.
  - `test_selfloop_end`: `jal x0, 0` retired twice ends with reason "selfloop".
  - `test_region_touch`: a load from 0x017F_FF80 sets `touched_region`.

**Interfaces:**

- [ ] **Step 1: Write the failing check.** `make -C verif/programs` then `python3 verif/cosim/run_cosim.py --all --v3` (Task 5 adds `--v3`; until then run `harness` per program). Expected: build failures on the new names.
- [ ] **Step 2: Implement the programs.** Each one is self-checking. It ends by writing
  `result_gpio = 0x5A` to GPIO_OUT on pass, or `0xEE` from the default trap or on a failed check,
  then self-loops.
  - `csr`: every contract-4 CSR field.
  - `trap_*`: one trap each. The handler checks mcause and mepc, adds 4 and returns with MRET.
  - `irq_timer`: timer compare at period 500 cycles. Count 20 interrupts; check TIMER_CAP is
    unused; check MIE masks.
  - `irq_stress` (Review Focus 2):
    - a GPIO edge interrupt fired by `gpio_script` every 37-91 cycles while the main loop runs
      taken branches, loads, stores and MRET-adjacent CSR toggles;
    - the handler records `mepc` and checks it is the address of an instruction the main loop
      has not yet executed (each main-loop instruction appends its pc to a trace);
    - plus WFI with MIE = 0 (must fall through when the edge comes).
  - `wfi`: WFI wakes on a GPIO edge with MIE = 1 and with MIE = 0.
  - `coherence` (Review Focus 3): store-then-load at the same address with every width and
    misalignment; copy a function from flash to PSRAM, jump to it, then overwrite one
    instruction and jump again (the new code must run).
  - `uart_echo` (Review Focus 4):
    - div = 39 (1 Mbaud at 40 MHz, fast enough for cosim);
    - echo 16 bytes from `uart_rx`, sent at +1% then at -1%;
    - send a byte while RX_FULL = 1 and check RX_OVR = 1 and the dropped byte;
    - `uart_tx_expect` is the echo.
  - `spi_loop`: D = 1; send 0x00..0x0F to the echo device and check each previous byte comes
    back.
  - `pwm`: PER = 99, Q = 1, duties 0 / 50 / 120 on the three channels, plus the timer in PWM mode on uo7 (P = 0, CMP = 300: high 300 of every 65,536 cycles). All are verified by the harness (`pwm` entries; the timer is `ch: 7`).
  - `ir_loop`: timer toggle output on uo7 looped to ui0 (`loop_uo7_to_ui0`). Capture both edges
    and check the capture deltas equal CMP+1 ticks ± 1.
  - `gpio_edge`: rising and falling flags per pin, W1C.
  - `mem_init_check`: data written to PSRAM is read back.

  All of them run under every seed, so Review Focus 1 is covered by the seed → mode mapping.
